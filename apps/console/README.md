# Engineering Console

Internal web console for testing and operating the liquid staking system:
executing contract messages, querying state, and inspecting system behavior
during development.

This is an internal engineering tool — it favors capability and directness
over end-user polish. The polished end-user experience lives in
[`apps/web/`](../web/).
